# RUSH ⚡

Rush, outdoor ve extreme spor etkinliklerini keşfetmek ve rezervasyon yapmak için geliştirilmiş mobil odaklı bir platformdur.

## 🚀 Özellikler (MVP)
- Etkinlik keşfi (outdoor & extreme sports)
- Filtreleme ve listeleme
- Etkinlik detay görüntüleme
- Rezervasyon / biletleme altyapısı (geliştirme aşamasında)
- Kullanıcı profili

## 🛠 Tech Stack
- Frontend: React Native (Expo)
- Backend: FastAPI
- Database: PostgreSQL
